# Workspace dependency decision · 2026-11-13

Scope: independently runnable React workspace, not the game engine or a provider SDK. Reviewed the repository shortlist, upstream docs and exact npm manifests before installing. Registry versions are pinned in package.json and package-lock.json. No service, key, hook, global installer or telemetry added.

| Choice                           | Reason / alternatives                                                                                                                                                                                                                                     | License / primary source                                         |
| -------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| React / React DOM 19.3.1         | Match the approved React 19/R3F direction. Built-in useSyncExternalStore keeps work state alive outside the panel. Zustand is reasonable when shared state grows; a second store dependency is unnecessary here.                                          | MIT · https://react.dev/reference/react/useSyncExternalStore     |
| Radix Dialog 1.3.1               | Reuse focus containment, dismissal and accessible labels. Used as a narrow in-world sheet; native dialog was considered but requires more lifecycle/focus handling in a controlled React host.                                                            | MIT · https://www.radix-ui.com/primitives/docs/components/dialog |
| Zod 4.6.7                        | Strict runtime boundaries with inferred types; avoids maintaining parallel handwritten validation. Ajv is a good alternative for a canonical JSON-schema-only bridge; the workspace owns a separate UI projection, not a replacement AgentEvent protocol. | MIT · https://zod.dev/                                           |
| Vite 8.3.8 / React plugin 6.3.0  | Small local demo host. No Next.js server needed. Node engine verified against local Node 24.13.1.                                                                                                                                                         | MIT · https://vite.dev/guide/                                    |
| TypeScript 5.9.3                 | Stable compatible compiler, strict mode; no need to migrate the slice to a newer compiler major.                                                                                                                                                          | Apache-2.0 · https://github.com/microsoft/TypeScript             |
| Vitest 5.1.0 / Playwright 1.65.0 | Adapter/state tests plus actual Chromium interactions, screenshots and trace on failure. Browser specs explicitly requested by the task.                                                                                                                  | MIT / Apache-2.0 · https://vitest.dev/ / https://playwright.dev/ |

Research stops with the runnable slice, audit and measured bundle. Actual installed transitive license and advisory results are recorded in VALIDATION.md. Runtime source dependencies also include tslib (0BSD); remaining runtime dependencies are MIT. Preserve the applicable third-party notices when packaging a distributable build. No third-party fonts, images or audio. The original small pixel glyphs are code-native rect grids under the repository Apache-2.0 license, not imported artwork. Revert this package to roll back; no root app or provider state is modified.
